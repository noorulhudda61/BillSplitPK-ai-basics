# BillSplitPK - Scope

## Idea
Bill splitter for Pakistani hostel students

## Problem
Splitting mess bills fairly is hard, calculations cause fights

## Solution
Enter total bill, number of friends, get equal split in PKR with clear breakdown

## Audience
Students in Islamabad hostels, friends sharing dinner bills

## MVP
Single HTML file, works offline, no login needed, mobile friendly

## Tech
HTML, CSS, JavaScript - Pure phone built
